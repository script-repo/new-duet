# Meeting scheduler

1. Check the calendar for the next 5 working days (`calendar_list`).
2. Offer two options at least a day apart, within working hours, avoiding back-to-back blocks.
3. Draft a short reply with both options. Keep the user's sign-off from memory.
4. If the other person already picked a time, create the event instead (`calendar_create`).
Sends and invites need the user's approval.
